# Cheatsheet — Aspen Adsorption 决策速查

## 工艺选型（再生方法）

| 场景 | 选型 | 理由 |
|---|---|---|
| 高压廉价、产品纯度要求高、解吸容易 | **PSA** | 压力摆动效率高、自动化程度高 |
| 解吸需要更低压、能耗敏感（CO₂、H₂） | **VPSA** | 真空度提升收率与纯度 |
| 同时富集塔顶轻 + 塔底重 | **DR-PSA** | 双回流；两端口均得高浓度产品 |
| 溶剂回收、利废热可用、循环速率可慢 | **TSA** | 低等级废热驱动；经济 |
| TSA 升温滞后影响产能 | **VTSA** | 抽真空+适度加热；减小滞后 |
| 无废热、紧凑装置、可接受能耗 | **ESA** | 电加热升温快；不节能 |

## 等温线方程速查

| 方程 | 适用 | 参数 | 何时不用 |
|---|---|---|---|
| Langmuir | 单层均匀、低中压 | IP1, IP2 | 高压非单层 |
| Langmuir-Freundlich/Toth | 非均匀、多孔分子筛、含温度修正 | IP1–IP6 | 想要最少参数时 |
| Freundlich | 经验、中压 | — | 高压（不物理） |
| BET | 多层、比表面积 | — | 单层体系 |
| Henry | 极低压 | — | 中高压 |
| User Procedure | 内置不匹配 | 自定义 | 标准体系别先用 |

## 模型组件默认选择

| 组件 | 默认 | 备选 |
|---|---|---|
| 传质速率 | **LDF**（∂qi/∂t = CMT·(q*i−qi)） | 固体扩散等 |
| 动量守恒/压降 | **Ergun 方程** | — |
| 床层维度 | **轴向一维** | 径向被忽略 |
| 颗粒形状 | **球状均匀**（SF ac = 1） | 实际颗粒填 ψ |
| 粒径 | **单一 Rp** | 分布需 User Procedure |

## 床层参数（必填）

| 符号 | 含义 | 单位 |
|---|---|---|
| Hb | 床层高度 | m |
| Db | 床层直径 | m |
| Ei | 颗粒间空隙率 | m³·m⁻³ |
| Ep | 颗粒内孔隙率 | m³·m⁻³ |
| RHOs | 吸附剂颗粒密度 | kg·m⁻³ |
| Rp | 吸附剂粒径 | m（单一值） |
| SF ac | 形状系数 | — |
| CMT | 传质系数 | s⁻¹ |
| IP | 等温线参数 | 最多 6 个 |

## 穿透曲线解读

| 现象 | 推断 | 行动 |
|---|---|---|
| 模拟 ≈ 实验 | 模型可信 | 进入 PSA/TSA 设计 |
| 模拟 > 实验（穿透晚） | 静态等温线高估动态吸附量 | 改用动态等温线 |
| 曲线尾巴长 | 传质阻力主导 | 检查 CMT、孔道扩散 |
| 曲线偏陡 | 吸附快、CMT 大 | 正常 |
| 高浓度 CO₂ 体系偏差 | 热效应被忽略 | 开启能量守恒 |

## PSA 循环步设计

| 阶段 | 母版 4 步 | 加 PE 节能 | VPSA |
|---|---|---|---|
| 1 | 升压 | 升压（用其他床余压） | 升压 |
| 2 | 吸附 | 吸附 | 吸附 |
| 3 | 降压 | 降压（向其他床充压） | 降压+抽真空 |
| 4 | 吹扫/置换 | 吹扫 | 吹扫+抽真空 |

## 床数放大决策

| 床数 | 阶段 | 用途 |
|---|---|---|
| 1 | 机理验证 | 单床 3–5 步、等温线+LDF 验证 |
| 2 | 双床原型 | 加 PE 步、初步连续化 |
| 4 | 工程化 | 主流配置；适合大多数 PSA |
| 6–12 | 规模化 | 高产能、多 PE；边际收益递减 |

## 偏差排查顺序

1. 等温参数 IP 是否实验回归
2. CMT 是否独立来源（非硬凑）
3. 床层均匀性（壁面效应、流速分布）
4. 热效应是否忽略（CO₂、胺改性体系必查）
5. 径向扩散
6. 孔径分布

## 三大已知失真边界

Aspen Adsorption 默认假设 ≈ "均匀球状颗粒 + 一维轴向 + 静态等温线 + 简化热平衡"。超出此域必须自定义或换 COMSOL/gPROMS。

- 高 CO₂ 浓度放热 → 必须开能量守恒。
- 宽孔径分布 MOF/分子筛 → User Procedure。
- 大规模工业床径向梯度 → COMSOL。

## 优化目标三元

工业吸附优化永远是 Pareto：
- **纯度 ↑**
- **回收率 ↑**
- **能耗 ↓**

Aspen Adsorption 给的就是这个 Pareto 面；三者互相牵制。
