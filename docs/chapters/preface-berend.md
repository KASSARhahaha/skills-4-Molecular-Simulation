# Berend Smit 中译本序

当杨凯告诉我，他和合作者正在将《理解分子模拟》翻译成中文时，我感到既惊喜又欣慰。

惊喜，是因为这本书最初只是Daan Frenkel和我写给学生的讲义，我们从未奢望它能走出英语世界。如今，三十年后的今天，它将以世界上使用人数最多的语言呈现在读者面前——这是任何作者都不敢奢望的荣幸。

欣慰，是因为在当今的科学研究中，语言不应成为获取知识的障碍。分子模拟已经从一个需要专门编程技能的小众领域，发展为化学、物理、材料科学和工程学研究的日常工具。在这一转变过程中，中国的研究群体发挥了至关重要的作用。近年来，中国学者在分子模拟领域的贡献令人瞩目——从新型多孔材料的计算筛选到复杂流体热力学性质的预测，从生物大分子的构象采样到能源材料的理性设计——中国已经成为全球分子模拟研究最活跃的社区之一。

杨凯是我的博士后，在洛桑联邦理工学院（EPFL）我的研究组工作期间，我们的合作非常愉快。他在分子模拟领域展现出了卓越的才能和独到的学术眼光，尤其在金属有机框架（MOF）和共价有机框架（COF）等多孔材料方向做出了出色且富有成效的工作。他不仅熟练掌握了书中的各种模拟方法，更将这些方法创造性地应用于实际体系，推动了MOF/COF领域的发展。因此，由他来主导这次中文翻译，我感到格外放心——翻译者本人就是一位活跃在分子模拟前沿的研究者，这在很大程度上保证了技术内容的准确性和翻译的学术水准。

我也很高兴看到他将这次翻译视为一项严肃的学术工作。在翻译过程中，原文中的公式、图表和参考文献得到了全面的核对与修正，术语的选择做了审慎的考量，并在必要时保留了英文原文以帮助读者对照。作为原作者，我认为这种处理方式非常恰当，也让我对中译本的质量充满信心。

我很乐意也很惊喜看到这本书被翻译成中文，扩展其在中国等国家和地区的影响力。一本好的教材能够在更广泛的读者群体中传播知识、培养人才，这是对学术社区最有价值的回馈。

借此机会，我也想谈谈这本书的核心理念——“理解”。Daan和我在写第一版时就确立了这一原则：本书不是模拟软件的使用手册，而是帮助读者理解模拟方法背后的物理原理。二十多年过去了，模拟软件变得更加易用，但“理解”的重要性不减反增。当一个模拟给出了意想不到的结果时，只有真正理解了方法原理的研究者才能判断：这是科学发现，还是模拟参数设置不当？我希望中文版的读者也能秉持这一精神来使用本书。

最后，我要感谢杨凯为这次翻译付出的巨大努力。翻译一本近五百页的技术著作是一项艰巨的工作，需要同时具备深厚的学科知识和出色的双语能力。我也要感谢赵丹（新加坡国立大学）对翻译工作的支持与帮助。

衷心祝愿他在清华大学的工作一切顺利，科研事业更上一层楼。

 Berend Smit
