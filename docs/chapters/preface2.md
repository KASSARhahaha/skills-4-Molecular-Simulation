# 第二版前言

为什么要写第二版？仅对第一版做轻微修订，纠正那些（确实不少的）排版错误，或许就已足够。然而，我们收到来自学生和同事的许多好评，最终往往伴随着这样的评论：“遗憾的是，你们没有讨论某某主题”。事实上，我们认为仅仅五年之后，模拟领域的变化如此之大，以至于书的内容已经无法涵盖其标题所蕴含的范围。

第一版写于 1995 年，此后出现了多种新技术，或者一些已有技术趋于成熟。第二版的大部分（但非全部）重大修改都涉及这些新进展。具体而言，我们增加了以下内容：

- 过渡路径采样和扩散势垒穿越，用于模拟稀有事件
- 耗散粒子动力学作为一种粗粒化模拟技术
- 计算长程力的新方案
- 在恒温和恒压分子动力学模拟背景下对哈密顿动力学和非哈密顿动力学的讨论
- 多重时间步长算法作为约束的替代方案
- 固体中的缺陷
- 针对复杂分子的修剪-增广 Rosenbluth 采样、回退生长和协同旋转
- 用于玻璃态哈密顿量的平行回火

我们更新了一些示例以纳入近期的工作。还添加了一些新的示例以说明最新的应用。

我们基于本书第一版开设了多次分子模拟课程。作为这些课程的一部分，Thijs Vlugt 博士准备了大量的习题、练习和案例研究，其中大部分已纳入本版。其他一些练习可在网上找到。我们非常感谢 Thijs Vlugt 允许我们复制这些材料。

本书描述的许多高级分子动力学技术是使用经典力学的拉格朗日形式或哈密顿形式推导的。然而，许多化学和化学工程的学生并不熟悉这些形式化体系。虽然对经典力学的全面描述显然超出了本书的范围，但我们添加了一个附录，概述了拉格朗日力学和哈密顿力学的核心要点。

特别感谢 Giovanni Ciccotti、Rob Groot、Gavin Crooks、Thijs Vlugt 和 Peter Bolhuis 对部分文本的评论。此外，我们感谢所有指出错误和排版错误的人，特别是 J.B. Freund、R. Akkermans 和 D. Moroni 博士。
