# 第一版前言

本书不是一本计算机模拟菜谱。我们的目标是解释分子模拟"配方"背后的物理原理。当然，我们也给出了这些配方本身，否则本书将过于抽象而缺乏实用价值。本书的范围必然是有限的：我们并不打算讨论计算机模拟的所有方面。相反，我们旨在对目前用于研究分子和超分子物质平衡性质，特别是相行为的计算工具进行统一的阐述。此外，我们有意识地将讨论局限于经典多体系统的模拟，尽管所提及的一些技术也可以应用于量子系统。在经典多体系统的范畴内，我们将讨论限制在对处于或接近平衡态的系统进行建模。

本书面向的是已经从事或计划从事计算机模拟的读者。计算机模拟工作者不断面临技术选择的难题，因为有令人眼花缭乱的各种计算工具可供使用。我们相信，要做出合理的选择，充分理解每种技术背后的物理原理是必不可少的。我们的目标正是为读者提供这样的背景知识。

我们应该在一开始就声明，我们认为某些技术比其他技术更有用，因此我们的介绍是有倾向性的。事实上，我们认为我们不将所有技术等量齐观地加以介绍，反而更能为读者服务。然而，每当我们表达个人偏好时，我们都尽量以物理学、应用数学或单纯以经验为基础的论证来支持。实际上，我们在介绍中穿插了实际案例，这些案例具有双重目的：首先，展示某种特定技术在实践中如何运作；其次，让读者领略数值模拟所能研究的各类现象。

读者还会注意到，有两个主题讨论得非常详细，即研究一级相变的模拟技术，以及构型偏倚Monte Carlo方法的各个方面。我们之所以花这么多篇幅讨论这些主题，并不是因为我们认为它们比其他涉及较少的主题更重要，而是因为我们认为目前文献中对这两个主题的讨论相当零散。

本引言是为非专家读者而写的。我们是有意这样做的。随着计算机实验成为通用的研究工具，从事计算机模拟的人群正在迅速扩大。许多新的模拟工作者将把计算机模拟作为一种工具使用，而不会对技术本身有主要兴趣。然而，我们希望说服那些将计算机模拟程序视为黑箱的读者：黑箱内部是很有趣的，更重要的是，更好地理解模拟程序的工作原理可以大大提高使用黑箱的效率。

除了理论框架之外，我们还讨论了一些在模拟界已成为"常识"并在模拟中常规使用的实用技巧和经验法则。通常很难追溯这些规则背后的原始动机。因此，某些"技巧"在一种情况下可能非常有用，但在其他情况下却可能导致低效的程序。在本书中，我们讨论各种技巧背后的原理，以便将它们置于适当的背景中。在正文部分，我们描述各种技术的理论框架。为了说明这些思想在实践中的应用方式，我们提供了算法、案例研究和示例。

## 算法

算法的描述构成本书的重要组成部分。然而，这种描述并不能提供太多关于如何高效实现算法的信息。当然，有关算法实现的细节可以从完整程序的代码清单中获取。但是，即使在一个结构良好的程序中，代码也包含许多虽然对于获得可工作程序来说是必要的，但往往会模糊其所表达算法本质的行。作为折中方案，我们为每种算法提供了伪代码。这些伪代码仅包含与所讨论算法直接相关的实现方面。这意味着，要在实际程序中使用这些伪代码，还必须添加一些必要的部分。例如，伪代码仅考虑$x$方向；如果要在模拟中使用该代码，还必须为$y$和$z$方向添加类似的语句。此外，我们省略了大多数变量的初始化。

## 案例研究

在案例研究中，正文中讨论的算法被组合成完整的程序。这些程序用于展示模拟的一些基本方面。一些案例研究侧重于模拟中可能出现的问题或有时会犯的错误。我们在案例研究中使用的FORTRAN代码的完整清单可以通过互联网[^1]获取。
